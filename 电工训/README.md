## 隐私处理

- 文件名、报告封面、重复身份栏和总结中的姓名、学号、院系、教师、分组与课次标识已移除。
- 智能插座报告中的实际 Wi-Fi 名称、密码和可识别网络配置已删除；四张配置截图改为占位说明，手机截图顶部信息已清理。测试文字、数据表格和其他技术图片保留。
- 报告文档属性、附件、脚本、外部链接及可发现的嵌入图片元数据已清理。PDF 内容经过实际删除和重新写入，未保留被遮盖的原文层。
- 照片采用精确遮盖方式，覆盖身份、分组、设备追踪标签及二维码；没有使用 AI 重绘。照片按 EXIF 方向规范显示后，以原尺寸无损 PNG 保存，移除时间、位置、设备等元数据，并验证遮盖区域以外的解码像素一致。
- PNG 用于避免重新压缩改变电路和设备细节，文件体积会大于原 JPEG。报告中原有实际网络配置已隐藏，需要复现实验时自行准备本机网络参数。

提交前检查和全仓库隐私范围见 [PRIVACY.md](../PRIVACY.md)。这些材料记录原实验过程与现象，脱敏版本不包含原作者身份和完整网络配置。
