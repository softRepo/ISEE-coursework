# A4：倒计时定时器

使用 Arduino UNO 与扩展板实现倒计时。旋转编码器选择预设时间，四位数码管显示分、秒，蜂鸣器在计时结束后提示；EEPROM 保存最近选择的时间档位。

设计报告记录电路方案，完整实验报告进一步记录了实际制板、焊接检查、上电调试和功能测试。制作阶段的接线与程序引脚映射见完整实验报告。
