# 数字系统设计实验

基于 Verilog HDL 和 Nexys Video 开发板的数字电路实验，使用 Vivado 与 ModelSim。主要实验包括流水灯、IP 核应用、组合电路、定时器、按键处理、DDS 和音乐播放器。

| 目录 | 内容 |
| --- | --- |
| [实验工程](实验工程/README.md) | 七组实验的源码、约束、仿真文件及工程配置 |
| [实验报告](实验报告/音乐播放器实验报告.pdf) | 音乐播放器报告，包含按键处理和 DDS 子实验；附 [LaTeX 源文件](实验报告/音乐播放器实验报告.tex) 与图片 |
| [实验指导书](实验指导书) | 实验 11、15、19 的指导材料 |
| [课程示例](课程示例/README.md) | 课程提供的程序框架、测试平台和接口网表 |
| [参考资料](参考资料/README.md) | 其他实现、组合电路与音乐播放器参考报告 |
| [复习资料](复习资料) | 上机练习回忆题、参考答案及相关电路图 |

实验工程相互独立，模块名可能重复，使用时请按单个实验建立工程。

报告源文件可使用 XeLaTeX 编译。图片路径均相对于对应的报告目录。
