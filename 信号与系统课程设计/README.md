# 信号与系统课程设计

[课程设计要求（Word）](课程设计要求.docx)

使用 MATLAB 完成音乐信号处理、图像频域滤波和孤立数字语音识别。

| 课题 | 内容 | 入口 |
| --- | --- | --- |
| 课题 ABC：音乐信号综合处理 | 回声与混响、FFT/STFT、采样重构、加噪与滤波 | [项目说明](课题ABC_音乐信号综合处理/README.md) · [设计报告](课题ABC_音乐信号综合处理/设计报告.pdf) |
| 课题 D：图像处理与频域分析 | 二维傅里叶变换、高斯低通与高通滤波 | [项目说明](课题D_图像处理与频域分析/README.md) · [设计报告](课题D_图像处理与频域分析/设计报告.pdf) |
| 课题 E：孤立数字语音识别 | 语音预处理、MFCC、DTW 模板匹配 | [项目说明](课题E_孤立数字语音识别/README.md) · [设计报告](课题E_孤立数字语音识别/设计报告.pdf) |

每个课题包含设计报告、MATLAB 源码、运行说明及实验结果图表。音乐片段和图像输入随源码提供；语音课题使用 FSDD，下载与存放方式见该课题的数据说明。

建议使用 MATLAB R2020a 或更高版本，安装 Signal Processing Toolbox 与 Image Processing Toolbox。
